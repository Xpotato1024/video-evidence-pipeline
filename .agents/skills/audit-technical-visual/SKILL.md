# audit-technical-visual

Use a fresh context with the visual audit request, source evidence and rendered files. Return checked targets, source-linked findings and execution identity. Only the human reviewer can approve a candidate.

The [exchange criteria](../../../config/lecture-guidance.yaml) define the material requirements. The [lecture workflow](../../../docs/operations/technical-lecture.md) defines the CLI handoff. This draft adapter is available for registry evaluation.
