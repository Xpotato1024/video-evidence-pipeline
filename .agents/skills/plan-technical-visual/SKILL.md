# plan-technical-visual

Use this draft procedure to evaluate the lecture exchange contract. The registry controls production
activation. The procedure applies only after VEP freezes the source and response contract.

## Inputs and outputs

Read the evidence, nearby math and derivation, then identify spatial relations, directions, boundaries,
time changes, cause/effect and comparisons the reader must see. Bind the figure ID, caption, alternative text,
data or geometry, and references to the same explanation. Use quantitative charts for numeric comparisons,
geometry for FBD/coordinate/boundary diagrams, and Mermaid for conceptual connections. Crop a bound source image
when accurate reconstruction is uncertain. Preserve units, sign conventions, baseline, load and support location,
and label measured, theoretical and illustrative data. Leave the uncertainty visible when the source is insufficient.

## Validation and stop conditions

Reconcile every labeled direction, quantity and condition with the surrounding steps and original source.
Stop if request identity, source access, or the required independent context cannot be verified.

## Boundaries

Do not use generated decorative imagery as evidence, omit data, or introduce unbound source assets.
Use the public CLI for deterministic validation and writes.
